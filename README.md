EPANET for SWMM5 Experts (The Rosetta Stone)

EPANET for SWMM5 Experts is a self-contained, interactive web app that helps stormwater engineers who already know SWMM5 make the mental shift to EPANET pressurized-network modeling. It organizes 32 tabs across concept mapping, hydraulics, components, water quality, modeling, data and tools, and reference, translating SWMM5 objects and behavior into their EPANET equivalents side by side rather than teaching EPANET from scratch.

The app includes interactive calculators and simulators for pipe head loss, force main roughness conversion, pump energy and cost, fire flow, and water hammer and transient response, along with animated canvases, Chart.js visualizations, and a 22-section EPANET Guide covering hydraulic theory, the Global Gradient Algorithm, calibration, and troubleshooting. It supports a US and SI unit toggle, eleven color themes, shareable URL state for specific tabs and inputs, and a browser-based generator for a printable reference document. It is built as a static HTML, CSS, and JavaScript application.
